追问与回答

问题1：能从名字判断是相册应用吗？

不能。仓库名不是源码证据。

问题2：LICENSE 能证明什么？

只能证明存在一份授权文本，不能证明功能、作者范围或交付状态。

问题3：为什么库存仍算有效 Git 仓？

它有有效 Git 元数据和提交记录；“有效 Git”不等于“有可分析源码”。

问题4：下一步怎么查？

核对远端、分支、sparse checkout、Git LFS、submodule 和历史，再向维护者确认。

问题5：面试时能讲什么？

只讲它证据不足、未作为项目使用；不讲功能、架构、测试或个人贡献。
