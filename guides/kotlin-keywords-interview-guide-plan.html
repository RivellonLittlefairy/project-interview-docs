Kotlin 关键字面试复习指南

目标：生成一份面向 Android 客户端面试、覆盖 Kotlin 官方关键字分类并带 Java 对照和客户端场景的离线单文件 HTML。

架构：正文使用语义化静态 HTML，卡片通过 data-* 属性提供检索元数据；内嵌 CSS 负责响应式版式，内嵌 JavaScript 只负责搜索、筛选、主题、目录和阅读进度增强。

技术栈：HTML5、CSS、原生 JavaScript、localStorage、PowerShell 静态检查、Chrome 响应式渲染验证。

全局约束

  • 交付文件固定为 docs/kotlin-keywords-interview-guide.html。
  • UTF-8、单文件、自包含、无 CDN、无第三方字体、无构建步骤。
  • 语言基线以 2026-08-15 查阅的 Kotlin 官方 2.4.10 文档为准；关键字页标记为 2026-06-24 更新。
  • 覆盖硬关键字、软关键字、修饰符关键字、特殊标识符、运算符与特殊符号。
  • 面向 Android 客户端；Java 对照和协程、Compose、ViewModel、Repository 场景是正文要求。
  • 高频条目深入，低频条目简略但必须可搜索、可定位。

任务 1 · 建立官方基线与覆盖清单

文件：创建并持续修改 docs/kotlin-keywords-interview-guide.html。

输入：Kotlin 官方 Keywords and operators、properties、inline functions、generics、coroutines、visibility modifiers、classes 页面。

输出：页面内 REQUIRED_TERMS 清单与来源说明。

  • 写入硬关键字清单：as、as?、break、class、continue、do、else、false、for、fun、if、in、!in、interface、is、!is、null、object、package、return、super、this、throw、true、try、typealias、typeof、val、var、when、while。
  • 写入软关键字清单：by、catch、constructor、delegate、dynamic、field、file、finally、get、import、init、param、property、receiver、set、setparam、value、where。
  • 写入修饰符清单：abstract、actual、annotation、companion、const、crossinline、data、enum、expect、external、final、infix、inline、inner、internal、lateinit、noinline、open、operator、out、override、private、protected、public、reified、sealed、suspend、tailrec、vararg。
  • 写入特殊标识符 field、it，以及官方运算符与特殊符号清单。
  • 加入来源链接、版本号、核对日期和“稳定/平台特定/版本敏感”说明。
  • 运行静态覆盖脚本，预期每个必需术语至少出现在清单和一张内容卡片中。
