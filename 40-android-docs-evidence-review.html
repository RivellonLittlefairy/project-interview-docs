3.3 初查事实性 MISS 的修订结果与“命名形态误报”

已修正的事实性 MISS

  1. Net.create(Service.class) 已改为真实门面 Net.createService(Service.class)，见 Net/net-api/src/main/java/com/zhihu/android/api/net/Net.java:41。
  2. 不存在的 NetProviderImpl.createRetrofit() 已改为在 initialize(...) 中创建 Retrofit.Builder 并构建 Retrofit，见同文件约 203—228 行。
  3. 不存在的 ZhPreplayerManager.preplayer() 已改为 preloadPlayer(dataSource) 创建/准备预播放器，getPreplayer(dataSource) 取出复用。
  4. “VipNet 缓存测试比 Net 更完整”已改为“两边保留同组缓存策略测试”；当前文档也如实记录 Net/net/src/test 33 个文件、VipNet/net/src/test 32 个。

不是事实性 MISS

  • MvxViewModel.collectState 不是顶层函数，而是 MvxViewModel 内对 Flow<T> 和 Observable<T> 定义的受保护成员扩展；文档写法可接受，若追求精确可注明“成员扩展”。
  • FragmentLauncher 是 Java interface。
  • ShareContentSharer、ZHImagesViewerEntrance、ResourceCenter、KMPlayer 是 Kotlin object。
  • 上述类型若仅用 class Xxx 搜索会假阴性，不能记为源码缺失。
